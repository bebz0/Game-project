# Game-project

A Python implementation of **Tetris** developed as a university project.

This repository contains the full source code, design artefacts, and presentation for a classic Tetris game using Python. The project demonstrates object-oriented design, game loop structure, rendering, and score management.

---

## 🧠 Project Overview

**Game-project** is a simple Tetris-style game written in Python.  
It was created as part of coursework and includes modular components for game logic, piece and grid management, rendering, and scoring.

### 🎯 Features

- Classic Tetris mechanics (falling pieces, rotation, line clearing)
- Separate modules for game logic and rendering
- Simple score tracking and game flow
- UML diagram and project presentation included
- Modular, beginner-friendly code structure
